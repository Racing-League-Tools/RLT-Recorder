# Third-party software

The release packages bundle the components below. Every package carries a
`THIRD-PARTY-NOTICES.txt` with each component's full copyright notice and
licence text, generated by `tools/build_dist.py` from the exact versions the
build used.

| Component | Licence | In |
|---|---|---|
| [.NET runtime](https://github.com/dotnet/runtime) | MIT (with its own third-party notices) | all |
| [Avalonia](https://github.com/AvaloniaUI/Avalonia) | MIT | window |
| [SkiaSharp](https://github.com/mono/SkiaSharp), with [Skia](https://skia.org) and the libraries it is built with | MIT; Skia BSD-3-Clause; others as listed in the notices | window |
| [HarfBuzzSharp](https://github.com/mono/SkiaSharp), with [HarfBuzz](https://github.com/harfbuzz/harfbuzz) | MIT; HarfBuzz "Old MIT" | window |
| [ANGLE](https://chromium.googlesource.com/angle/angle) | BSD-3-Clause | Windows window |
| [MicroCom.Runtime](https://github.com/kekekeks/MicroCom) | MIT | window |
| [Tmds.DBus.Protocol](https://github.com/tmds/Tmds.DBus) | MIT | window |
| [libICE, libSM](https://gitlab.freedesktop.org/xorg/lib) (X.Org, binaries from Debian 12) | MIT/X11; texts in `deploy/linux/lib` | Linux window |
| [Serilog](https://github.com/serilog/serilog), Serilog.Sinks.Console, Serilog.Sinks.File | Apache-2.0 | all (used by the vendored dumper) |

The Racing League Tools name and logo are not covered by any of these
licences, nor by this project's own; see the README.
